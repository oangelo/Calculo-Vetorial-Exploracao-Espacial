• EXERCÍCIO VECTOR-4C
    ORIGEM: Relatório Final - Programa Gemini [DEZ/1966]

    Para encerrar, vamos analisar uma função que combina vários dos conceitos explorados ao longo da lista: descontinuidade em uma superfície, limitação e domínio não trivial.

    Considere a função: \[\Gamma(x,y,z) = \begin{cases} \frac{x^2 z}{x^2 + y^2} & \text{se } (x,y) \neq (0,0), \\ 0 & \text{se } x = y = 0, \end{cases}\] definida no cilindro \(V = \{(x,y,z) \mid x^2 + y^2 \le 1,\, 0 \le z \le 2\}\).

    (a) Identifique os pontos ou superfícies problemáticos de \(\Gamma\). Onde a função pode ser descontínua?

    (b) Verifique se \(\Gamma\) é limitada em \(V\). Determine cotas para \(\left|\frac{x^2}{x^2+y^2}\right|\).

    (c) Analise o conjunto de descontinuidade: qual é a dimensão geométrica desse conjunto em \(\mathbb{R}^3\)? Tem medida nula?

    (d) Conclua sobre a integrabilidade de \(\Gamma\) em \(V\), mobilizando os conceitos de medida nula, limitação e descontinuidade.

    RELATÓRIO DE CÁLCULO [SIGMA-12 REQUERIDO]

    (a) O único ponto problemático é o eixo \(z\) (\(x = y = 0\)), onde o denominador \(x^2+y^2\) se anula. Para \((x,y) \neq (0,0)\), a função é quociente de polinômios com denominador não nulo, logo contínua. A questão é se a definição \(\Gamma(0,0,z) = 0\) torna a função contínua no eixo \(z\).

    Aproximando-se da origem ao longo do eixo \(x\): \(\Gamma(x,0,z) = \frac{x^2 \cdot z}{x^2} = z\) para \(x \neq 0\), enquanto \(\Gamma(0,0,z) = 0\). Logo, para \(z \neq 0\), o limite é \(z \neq 0 = \Gamma(0,0,z)\). A função é descontínua ao longo de todo o eixo \(z\) (exceto em \(z = 0\), onde o limite coincide com o valor).

    (b) Como \(x^2 \le x^2+y^2\) para todo \((x,y)\), temos \(0 \le \frac{x^2}{x^2+y^2} \le 1\). Com \(0 \le z \le 2\), obtemos \(0 \le \Gamma(x,y,z) = \frac{x^2}{x^2+y^2}\cdot z \le 1 \cdot 2 = 2\). A função é limitada: \(0 \le \Gamma \le 2\).

    (c) O conjunto de descontinuidade é o segmento de reta \(\{(0,0,z) \mid 0 \le z \le 2\}\) — o eixo \(z\) dentro do cilindro. Trata-se de um segmento de reta (unidimensional) em \(\mathbb{R}^3\). Um segmento de reta tem medida nula em 3D (volume zero), assim como no plano uma reta tem área zero.

    (d) A integral de \(\Gamma\) em \(V\) existe. Resumo: (1) \(\Gamma\) é limitada (\(0 \le \Gamma \le 2\)); (2) o conjunto de descontinuidade é um segmento de reta, que tem medida nula em \(\mathbb{R}^3\); (3) \(V\) é limitado (cilindro de raio 1 e altura 2). Este exercício combina todos os conceitos da lista: a função tem uma descontinuidade "escondida" (ao longo de uma reta inteira, não em um ponto isolado), é limitada apesar da forma fracionária, e o conjunto problemático é "fino o bastante" (medida nula em 3D) para não comprometer a integral.
