• EXERCÍCIO VECTOR-2B
    ORIGEM: Simulação de Trajetória - GEMINI-IV

    Além de escala, podemos usar somas cumulativas — cada variável acumula as anteriores. Isso simplifica regiões onde os limites de cada variável dependem de todas as que vêm antes, criando uma dependência em cascata.

    Calcule \(\iiint_D xz\,dV\) na região definida por \[0 \le x \le 1, \quad 0 \le y \le 1-x, \quad 0 \le z \le 1-x-y.\]

    (a) Proponha a transformação \(u = x\), \(v = x+y\), \(w = x+y+z\) e obtenha a inversa, expressando \(x\), \(y\), \(z\) em termos de \(u\), \(v\), \(w\).

    (b) Determine os novos limites de integração e calcule o Jacobiano.

    (c) Reescreva a integral em \((u,v,w)\) e avalie.

    ARQUIVO AUXILIAR [SIGMA-2]
    [NOTA TÉCNICA]: A inversa é simples subtração: \(y = v - u\), \(z = w - v\). A matriz jacobiana dessa transformação é triangular inferior com uns na diagonal — o determinante é \(1\). Para os limites, cada restrição original (\(y \ge 0\), \(z \ge 0\)) vira uma desigualdade entre as novas variáveis.
    RELATÓRIO DE CÁLCULO [SIGMA-2 REQUERIDO]

    (a) A inversa é \(x = u\), \(y = v - u\), \(z = w - v\). Verificação: \(u + (v-u) + (w-v) = w\), consistente.

    (b) As restrições originais se traduzem: \(x \ge 0 \Rightarrow u \ge 0\); \(y \ge 0 \Rightarrow v \ge u\); \(z \ge 0 \Rightarrow w \ge v\); \(x \le 1 \Rightarrow u \le 1\); \(x+y \le 1 \Rightarrow v \le 1\); \(x+y+z \le 1 \Rightarrow w \le 1\).

    Os limites são \(0 \le u \le 1\), \(u \le v \le 1\), \(v \le w \le 1\). O Jacobiano é \(\left|\frac{\partial(x,y,z)}{\partial(u,v,w)}\right| = 1\) (matriz triangular com diagonal \(1,1,1\)).

    (c) A integrando: \(xz = u(w-v)\). A integral fica \[ \int_{u=0}^{1}\int_{v=u}^{1}\int_{w=v}^{1} u(w-v)\;dw\,dv\,du.\]

    Integração em \(w\): \(\int_v^1 (w-v)\,dw = \frac{(1-v)^2}{2}\).

    Integração em \(v\): \(\int_u^1 u \cdot \frac{(1-v)^2}{2}\,dv = \frac{u}{2}\left[-\frac{(1-v)^3}{3}\right]_u^1 = \frac{u(1-u)^3}{6}\).

    Integração em \(u\): \(\int_0^1 \frac{u(1-u)^3}{6}\,du = \frac{1}{6}\left[\frac{(1-u)^4(4u+1)}{20}\right]_0^1 = \frac{1}{6} \cdot \frac{1}{20} = \frac{1}{120}.\)
