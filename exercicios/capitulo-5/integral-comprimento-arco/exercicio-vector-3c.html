• EXERCÍCIO VECTOR-3C
    ORIGEM: Análise Pós-Apollo 8 - Relatório de Desempenho Orbital [REF: RPT-503/JAN-1969]

    Componentes exponenciais simplificam com identidades hiperbólicas. Componentes trigonométricas também podem reservar surpresas. Vamos investigar uma curva cujo integrando não simplifica diretamente — o aluno deve fatorar termos comuns e usar identidades para revelar uma expressão integrável.

    Considere a curva plana \(\vec{r}(t) = \bigl(\cos^3 t,\, \sin^3 t\bigr)\), com \(t\) variando de 0 a \(\pi/2\).

    (a) Calcule \(\vec{r}\,'(t)\).

    (b) Calcule \(\|\vec{r}\,'(t)\|^2\) e mostre que ela se reduz a \(\frac{9}{4}\sin^2(2t)\). Que identidade trigonométrica permite essa redução?

    (c) Integre usando a substituição \(u = 2t\) e obtenha o comprimento \(L\).

    ARQUIVO AUXILIAR [SIGMA-3]
    [NOTA TÉCNICA]: Ao calcular \(\|\vec{r}\,'(t)\|^2\), fatore os termos comuns em \(\sin^2 t\) e \(\cos^2 t\). A expressão fatorada conterá \(\sin^2 t + \cos^2 t\) como fator — use a identidade fundamental. Depois, empregue \(\sin t \cos t = \frac{1}{2}\sin(2t)\) para reduzir a uma integral direta.
    RELATÓRIO DE CÁLCULO [SIGMA-3 REQUERIDO]

    (a) \(\vec{r}\,'(t) = (-3\cos^2 t \sin t,\, 3\sin^2 t \cos t)\).

    (b)

    \[\|\vec{r}\,'(t)\|^2 = 9\cos^4 t \sin^2 t + 9\sin^4 t \cos^2 t = 9\sin^2 t \cos^2 t (\cos^2 t + \sin^2 t)\]

    Pela identidade \(\cos^2 t + \sin^2 t = 1\):

    \[\|\vec{r}\,'(t)\|^2 = 9\sin^2 t \cos^2 t\]

    Usando \(\sin t \cos t = \frac{1}{2}\sin(2t)\):

    \[\|\vec{r}\,'(t)\|^2 = 9 \cdot \frac{1}{4}\sin^2(2t) = \frac{9}{4}\sin^2(2t)\]

    Portanto \(\|\vec{r}\,'(t)\| = \frac{3}{2}\sin(2t)\) (pois \(\sin(2t) \geq 0\) para \(t \in [0, \pi/2]\)).

    (c) Substituição \(u = 2t\), \(du = 2\, dt\):

    \[L = \int_0^{\pi/2} \frac{3}{2}\sin(2t)\, dt = \frac{3}{2} \cdot \frac{1}{2}\int_0^{\pi} \sin u\, du = \frac{3}{4}\bigl[-\cos u\bigr]_0^{\pi}\]

    \[= \frac{3}{4}\bigl(-\cos\pi + \cos 0\bigr) = \frac{3}{4}(1+1) = \frac{3}{2}\]

    O comprimento é \(L = 3/2\). A curva \((\cos^3 t, \sin^3 t)\) é um arco de astroide — uma curva com propriedades notáveis. A fatoração foi o passo crucial: sem ela, o integrando pareceria intratável.
