• EXERCÍCIO VECTOR-3B
    ORIGEM: Apollo 8 - Classificação de Órbitas - DEZEMBRO/1968

    A orientação que estudamos ganha importância especial quando a curva volta ao ponto de partida — uma curva fechada, como uma órbita. Analise as quatro parametrizações a seguir:

    Curva I: \(\vec{r}_1(t) = (\cos t,\; \sin t)\), \(t \in [0, 2\pi]\)

    Curva II: \(\vec{r}_2(t) = (\cos t,\; \sin 2t)\), \(t \in [0, 2\pi]\)

    Curva III: \(\vec{r}_3(t) = (t,\; t^2)\), \(t \in [0, 1]\)

    Curva IV: \(\vec{r}_4(t) = (\cos t,\; 2\sin t)\), \(t \in [0, 2\pi]\)

    (a) Para cada curva, verifique a condição de fechamento: \(\vec{r}(a) = \vec{r}(b)\)? Classifique cada curva como fechada ou aberta.

    (b) Entre as curvas fechadas, investigue se há autointerseções — pontos onde a curva cruza consigo mesma em valores diferentes de \(t\). Dica: para a Curva II, verifique se existem \(t_1 \neq t_2\) com \(\vec{r}_2(t_1) = \vec{r}_2(t_2)\).

    (c) Classifique cada curva fechada como simples (sem autointerseções) ou não simples (com autointerseções). Faça um esboço de cada uma.

    ARQUIVO AUXILIAR [SIGMA-5]
    [NOTA TÉCNICA]: Para verificar autointerseções na Curva II, tente \(t_1 = 0\) e \(t_2 = \pi\): \(\vec{r}_2(0) = (1,0)\) e \(\vec{r}_2(\pi) = (1, 0)\). A curva passa por \((1,0)\) em dois momentos diferentes — portanto, não é simples. Para as Curvas I e IV, use o fato de que \((\cos t, k\sin t)\) percorre uma elipse sem autointerseções quando \(t\) varia numa volta completa.
