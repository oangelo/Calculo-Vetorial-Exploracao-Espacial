• EXERCÍCIO VECTOR-4A
    ORIGEM: Programa Apollo - Teoria Geral de Trajetórias - 1969

    Nos exercícios anteriores, classificamos curvas específicas — uma a uma. Podemos provar propriedades para famílias inteiras de curvas? Considere a família paramétrica

    \[\vec{r}_\alpha(t) = (t^3 + \alpha t,\; t^2 + \alpha), \quad t \in [-1,1]\]

    onde \(\alpha\) é um parâmetro real. Cada valor de \(\alpha\) define uma curva diferente. O objetivo é determinar para quais valores de \(\alpha\) a curva é suave.

    (a) Calcule \(\vec{r}_\alpha\,'(t)\) para o caso geral. Verifique que a curva é \(C^1\) para todo \(\alpha \in \mathbb{R}\).

    (b) Determine para quais valores de \(\alpha\) o vetor derivada se anula em algum ponto do intervalo \([-1,1]\). Conclua: para quais valores de \(\alpha\) a curva é suave?

    (c) Interprete geometricamente: para o valor de \(\alpha\) que torna a curva não-suave, esboce a curva e identifique o ponto problemático. Que tipo de singularidade aparece?
