• EXERCÍCIO VECTOR-4B
    ORIGEM: Apollo 11 — JUL/1969

    O campo gravitacional é conservativo, como vimos. Vamos usar essa propriedade para planejar uma manobra de transferência orbital. O potencial oferece um atalho: sem integrar ao longo do caminho, obtemos o trabalho diretamente.

    Considere o campo \(\vec{F}(x,y,z) = (2x + yz,\; 2y + xz,\; 2z + xy)\). Uma nave deve ser movida do ponto \(A = (1, 0, 0)\) ao ponto \(B = (0, 2, 1)\). O caminho planejado é o segmento de reta \(\vec{r}(t) = (1-t,\; 2t,\; t)\), \(0 \leq t \leq 1\).

    (a) Determine se \(\vec{F}\) é conservativo: calcule \(\nabla \times \vec{F}\) e verifique o domínio.

    (b) Se for conservativo, encontre a função potencial \(\Phi(x,y,z)\).

    (c) Calcule o trabalho usando apenas o potencial: \(W = \Phi(B) - \Phi(A)\).

    (d) Verifique calculando a integral de linha diretamente ao longo do caminho \(\vec{r}(t)\). Os resultados coincidem?

    RELATÓRIO DE CÁLCULO [SIGMA-4 REQUERIDO]

    (a) \(\nabla \times \vec{F}\): componente \(i\): \(\partial(2z+xy)/\partial y - \partial(2y+xz)/\partial z = x - x = 0\); componente \(j\): \(\partial(2x+yz)/\partial z - \partial(2z+xy)/\partial x = y - y = 0\); componente \(k\): \(\partial(2y+xz)/\partial x - \partial(2x+yz)/\partial y = z - z = 0\). \(\nabla \times \vec{F} = \vec{0}\) em \(\mathbb{R}^3\) (simplesmente conexo). Logo \(\vec{F}\) é conservativo.

    (b) \(\Phi = \int (2x+yz)\,dx = x^2 + xyz + C(y,z)\). \(\partial\Phi/\partial y = xz + \partial C/\partial y = 2y + xz \Rightarrow \partial C/\partial y = 2y \Rightarrow C = y^2 + D(z)\). \(\partial\Phi/\partial z = xy + D'(z) = 2z + xy \Rightarrow D'(z) = 2z \Rightarrow D = z^2\). \(\Phi(x,y,z) = x^2 + xyz + y^2 + z^2 + K\).

    (c) \(\Phi(A) = \Phi(1,0,0) = 1 + 0 + 0 + 0 = 1\). \(\Phi(B) = \Phi(0,2,1) = 0 + 0 + 4 + 1 = 5\). \(W = \Phi(B) - \Phi(A) = 5 - 1 = 4\).

    (d) \(\vec{r}(t) = (1-t,\, 2t,\, t)\), \(\vec{r}'(t) = (-1,\, 2,\, 1)\). \(\vec{F}(\vec{r}(t)) = (2(1-t)+2t^2,\; 2(2t)+(1-t)t,\; 2t+(1-t)2t) = (2-2t+2t^2,\; 4t+t-t^2,\; 4t-2t^2)\). \(\vec{F} \cdot \vec{r}' = -(2-2t+2t^2) + 2(4t+t-t^2) + (4t-2t^2) = -2+16t-6t^2\). \(\displaystyle\int_0^1 (-2+16t-6t^2)\,dt = [-2t+8t^2-2t^3]_0^1 = -2+8-2 = 4\). Os resultados coincidem: \(W = 4\). \(\checkmark\)
