• EXERCÍCIO VECTOR-3A
    ORIGEM: Planejamento de Manobra Orbital – Apollo 8, DEZ/1968

    Agora que sabemos encontrar \(\Phi\) em 2D e 3D, vamos usar esse poder para resolver um problema prático de navegação. Em vez de parametrizar curvas e integrar, basta conhecer \(\Phi\) em dois pontos. Considere o campo \(\vec{F}(x,y,z) = (yz,\; xz,\; xy)\), que modela o campo gravitacional lunar simplificado durante orbitagem.

    (a) Encontre a função potencial \(\Phi\) deste campo.

    (b) Calcule o trabalho para a manobra de \(A = (1,2,0)\) ao ponto \(B = (2,1,1)\).

    (c) Calcule o trabalho para uma segunda manobra de \(B\) ao ponto \(C = (1,3,2)\).

    (d) Compare o trabalho total de \(A \to B \to C\) com o trabalho direto de \(A \to C\). O resultado era previsível? Por quê?

    ARQUIVO AUXILIAR [SIGMA-3]
    [NOTA TÉCNICA]: Observe a simetria: todas as componentes de \(\vec{F}\) são produtos de duas variáveis. Pense em que função de três variáveis tem derivadas parciais iguais a \(yz\), \(xz\) e \(xy\). Para o item (d), lembre: se \(\Phi\) existe, o trabalho de \(A\) a \(C\) é sempre \(\Phi(C) - \Phi(A)\), seja qual for o trajeto intermediário.
    RELATÓRIO DE CÁLCULO [SIGMA-3 REQUERIDO]

    (a) \(\frac{\partial \Phi}{\partial x} = yz \Rightarrow \Phi = xyz + g(y,z)\). Derivando em \(y\): \(xz + g_y = xz \Rightarrow g_y = 0\). Derivando em \(z\): \(xy + g_z = xy \Rightarrow g_z = 0\). Logo \(g = C\). Tomando \(C = 0\): \(\Phi(x,y,z) = xyz\).

    (b) Trabalho \(= \Phi(2,1,1) - \Phi(1,2,0) = 2 - 0 = 2\).

    (c) Trabalho \(= \Phi(1,3,2) - \Phi(2,1,1) = 6 - 2 = 4\).

    (d) Trabalho total \(A \to B \to C = 2 + 4 = 6\). Trabalho direto \(A \to C = \Phi(1,3,2) - \Phi(1,2,0) = 6 - 0 = 6\). Os resultados coincidem porque \(\Phi\) existe: o trabalho independe do caminho, e passar por \(B\) não altera o custo total de \(A\) a \(C\).
