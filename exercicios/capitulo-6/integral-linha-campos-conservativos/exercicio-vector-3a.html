• EXERCÍCIO VECTOR-3A
    ORIGEM: Estudo de Injeção Translunar – Apollo X [18/MAI/1969]

    Até agora trabalhamos apenas em \(\mathbb{R}^2\). O astronauta opera em três dimensões — o procedimento se estende naturalmente. Vamos aplicá-lo ao campo gravitacional, que é fisicamente relevante e tem um potencial que já conhecemos. O campo gravitacional simplificado é dado por \(\vec{F}(\vec{r}) = -k\,\dfrac{\vec{r}}{|\vec{r}|^3}\), onde \(k > 0\) é uma constante e \(\vec{r} = (x, y, z)\).

    (a) Reconheça a função potencial: verifique que \(\phi(\vec{r}) = k/|\vec{r}|\) satisfaz \(\vec{F} = \nabla\phi\) (na verdade, \(\vec{F} = -\nabla(k/|\vec{r}|)\); convencionamos \(\phi = -k/|\vec{r}|\) para que \(\vec{F} = \nabla\phi\)). Calcule \(\nabla(-k/|\vec{r}|)\) e confirme.

    (b) Explique por que o trabalho para mover uma nave de uma órbita circular de raio \(r = a\) para outra de raio \(r = b\) não depende da trajetória específica da transferência.

    (c) Calcule o trabalho \(W = \phi(B) - \phi(A)\) em função de \(a\) e \(b\), onde \(A\) está a distância \(a\) do centro e \(B\) a distância \(b\). Interprete o sinal: quando \(b > a\) (órbita mais alta), o trabalho é positivo ou negativo? O que isso significa fisicamente?

    ARQUIVO AUXILIAR [SIGMA-3]
    [NOTA TÉCNICA]: O potencial gravitacional é \(\phi = -k/|\vec{r}|\). Para um ponto a distância \(r\) do centro, \(\phi = -k/r\). A diferença de potencial é \(\phi(b) - \phi(a) = -k/b + k/a = k(1/a - 1/b)\).
    RELATÓRIO DE CÁLCULO [SIGMA-3 REQUERIDO]

    (a) \(\phi = -k/|\vec{r}| = -k(x^2+y^2+z^2)^{-1/2}\). \(\partial\phi/\partial x = kx(x^2+y^2+z^2)^{-3/2} = -(-kx/|\vec{r}|^3)\). Na verdade, \(\nabla\phi = k\vec{r}/|\vec{r}|^3\), mas o campo gravitacional é \(\vec{F} = -k\vec{r}/|\vec{r}|^3\). Para que \(\vec{F} = \nabla\phi\), tomamos \(\phi = -k/|\vec{r}|\). Confirma-se: \(\nabla(-k/|\vec{r}|) = k\vec{r}/|\vec{r}|^3 \cdot (-1) = -k\vec{r}/|\vec{r}|^3 = \vec{F}\).

    (b) O campo gravitacional é conservativo, logo a integral depende apenas dos extremos. Não importa se a nave segue uma trajetória de Hohmann, uma transferência direta ou qualquer outro caminho: o trabalho é o mesmo.

    (c) \(W = \phi(B) - \phi(A) = (-k/b) - (-k/a) = k/a - k/b = k\left(\frac{1}{a} - \frac{1}{b}\right)\). Para \(b > a\): \(1/a > 1/b\), logo \(W > 0\). Trabalho positivo significa que é necessário fornecer energia para subir a órbita.
