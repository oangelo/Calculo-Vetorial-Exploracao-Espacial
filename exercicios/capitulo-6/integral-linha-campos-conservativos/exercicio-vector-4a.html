• EXERCÍCIO VECTOR-4A
    ORIGEM: Missão Ômega – Análise Paramétrica de Estabilidade [CONFIDENCIAL – 01/JUN/1969]

    O campo \(\vec{F}(x,y) = (2x + ay,\, x + 2y)\) depende de um parâmetro \(a \in \mathbb{R}\). Dependendo do valor de \(a\), o campo pode ou não ser conservativo.

    (a) Aplique o teste de conservatividade (derivadas cruzadas) e determine o valor de \(a\) para o qual o campo é conservativo.

    (b) Para o valor de \(a\) encontrado, determine a função potencial \(\phi\) integrando componente a componente.

    (c) Calcule a integral de linha de \(A = (0, 0)\) a \(B = (1, 2)\) usando o potencial.

    RELATÓRIO DE CÁLCULO [SIGMA-4 REQUERIDO]

    (a) \(\partial F_1/\partial y = a\) e \(\partial F_2/\partial x = 1\). Para conservatividade: \(a = 1\).

    (b) Com \(a = 1\): \(\vec{F} = (2x + y,\, x + 2y)\). Integrando \(F_1 = 2x + y\) em \(x\): \(\phi = x^2 + xy + g(y)\). Derivando em \(y\): \(\partial\phi/\partial y = x + g'(y) = x + 2y\). Logo \(g'(y) = 2y\), \(g(y) = y^2\). \(\phi(x,y) = x^2 + xy + y^2\).

    (c) \(\phi(1,2) - \phi(0,0) = (1 + 2 + 4) - 0 = 7\).
