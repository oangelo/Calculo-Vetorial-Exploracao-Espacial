• EXERCÍCIO VECTOR-2A
    ORIGEM: Lab. de Navegação Orbital – Apollo 16 [21/ABR/1972]

    Até agora usamos apenas parametrizações, mas muitas superfícies vêm dadas na forma implícita \(F(x,y,z) = K\). Será que existe um atalho para encontrar o plano tangente sem parametrizar? Considere a esfera

    \[x^2 + y^2 + z^2 = 9\]

    e o ponto \(P = (2, 1, 2)\) sobre ela.

    (a) Calcule o gradiente \(\nabla F\) no ponto \(P\), onde \(F(x,y,z) = x^2 + y^2 + z^2\).

    (b) Parametrize a mesma esfera usando coordenadas esféricas \(\vec{r}(\theta,\phi) = (3\sin\phi\cos\theta, 3\sin\phi\sin\theta, 3\cos\phi)\). Encontre os valores de \(\theta\) e \(\phi\) correspondentes ao ponto \(P\), calcule \(\vec{r}_\theta \times \vec{r}_\phi\) nesse ponto e compare com o gradiente de (a). Os vetores são paralelos?

    (c) Escreva a equação do plano tangente usando o gradiente. Verifique que o mesmo plano é obtido pelo método paramétrico.

    ARQUIVO AUXILIAR [SIGMA-2]
    [NOTA TÉCNICA]: Para comparar os dois métodos, lembre-se que dois vetores são paralelos se um é múltiplo escalar do outro. Não é necessário que tenham o mesmo módulo ou sentido — apenas a mesma direção.
    RELATÓRIO DE CÁLCULO [SIGMA-4 REQUERIDO]

    (a) \(\nabla F = (2x, 2y, 2z)\). Em \(P=(2,1,2)\): \(\nabla F = (4, 2, 4)\).

    (b) De \(3\cos\phi = 2\), obtemos \(\cos\phi = 2/3\). De \(3\sin\phi\cos\theta = 2\) e \(3\sin\phi\sin\theta = 1\), obtemos \(\tan\theta = 1/2\). Calculando \(\vec{r}_\theta \times \vec{r}_\phi\) e avaliando no ponto, obtemos um vetor proporcional a \((2,1,2)\), que é paralelo a \(\nabla F = (4,2,4) = 2(2,1,2)\).

    (c) Plano via gradiente: \((4,2,4) \cdot (x-2, y-1, z-2) = 0\), ou \(4x + 2y + 4z = 18\), que simplifica para \(2x + y + 2z = 9\). Pelo método paramétrico, usando \(\vec{n} = (2,1,2)\): \(2(x-2) + (y-1) + 2(z-2) = 0\), que dá o mesmo resultado.
