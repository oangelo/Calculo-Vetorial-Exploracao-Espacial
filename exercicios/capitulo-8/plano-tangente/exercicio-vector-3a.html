• EXERCÍCIO VECTOR-3A
    ORIGEM: Centro de Planejamento de Rover – Apollo 16 [21/ABR/1972]

    Agora que dominamos os dois métodos, podemos usá-los como ferramenta para responder perguntas geométricas mais sofisticadas. Por exemplo: em que pontos de uma superfície o plano tangente é horizontal? Isso é crucial para identificar regiões planas no terreno lunar onde o rover pode operar com maior estabilidade. Considere a superfície dada como gráfico

    \[z = x^3 - 3x + y^3 - 3y\]

    (a) Determine a condição para que o plano tangente seja horizontal. O que significa "horizontal" em termos do vetor normal?

    (b) Encontre todos os pontos \((x,y,z)\) da superfície onde o plano tangente é horizontal.

    (c) Interprete geometricamente: esses pontos coincidem com os pontos críticos da função \(f(x,y) = x^3 - 3x + y^3 - 3y\)? Conecte com o conceito de curvas de nível do Capítulo 0.

    ARQUIVO AUXILIAR [SIGMA-3]
    [NOTA TÉCNICA]: Um plano é horizontal quando seu vetor normal é vertical, ou seja, paralelo ao eixo \(z\). Para uma superfície \(z = f(x,y)\), o vetor normal via gradiente de \(F = z - f(x,y)\) é \(\nabla F = (-f_x, -f_y, 1)\). Para que este vetor seja vertical, precisamos \(f_x = 0\) e \(f_y = 0\).
    RELATÓRIO DE CÁLCULO [SIGMA-4 REQUERIDO]

    (a) Plano tangente horizontal \(\Leftrightarrow\) normal vertical \(\Leftrightarrow\) \(\nabla F = (0,0,1)\) (ou múltiplo). Isso exige \(f_x = 0\) e \(f_y = 0\).

    (b) \(f_x = 3x^2 - 3 = 0 \Rightarrow x = \pm 1\). \(f_y = 3y^2 - 3 = 0 \Rightarrow y = \pm 1\). Os pontos são: \((1,1,-4)\), \((1,-1,-2)\), \((-1,1,-2)\), \((-1,-1,0)\).

    (c) Sim, são exatamente os pontos críticos de \(f(x,y)\). O gradiente \(\nabla f = (f_x, f_y)\) se anula nesses pontos, o que significa que as curvas de nível se "achatam" localmente — o terreno é plano na vizinhança.
