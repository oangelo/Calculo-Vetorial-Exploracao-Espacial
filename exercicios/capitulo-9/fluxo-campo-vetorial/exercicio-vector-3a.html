• EXERCÍCIO VECTOR-3A
    ORIGEM: Skylab I — Módulo hemisférico pressurizado, novembro de 1973

    O hemisfério do exercício anterior é uma superfície aberta — tem um buraco na base. E se fecharmos esse buraco? O módulo hemisférico do Skylab é selado com um disco no plano \(z = 0\), formando uma superfície fechada. Vamos calcular o fluxo total do campo radial \(\vec{F} = (x,\, y,\, z)\) através dessa superfície composta.

    A superfície fechada \(S = S_1 \cup S_2\) consiste de:

    \(S_1\): hemisfério superior de raio \(2\) (\(x^2 + y^2 + z^2 = 4\), \(z \geq 0\)) — já calculado no exercício anterior.
    \(S_2\): disco \(x^2 + y^2 \leq 4\) no plano \(z = 0\) — a base que fecha o volume.

    (a) Determine o vetor normal unitário correto para o disco \(S_2\), usando a convenção de orientação para fora do volume hemisférico. (Atenção: "para fora" do volume significa para baixo neste caso, já que o volume está acima do disco.)

    (b) Calcule o fluxo através do disco \(S_2\). Observe que, no plano \(z = 0\), o campo é \(\vec{F}(x,y,0) = (x,\, y,\, 0)\). O que acontece quando você faz o produto escalar com a normal do disco?

    (c) Some os fluxos de \(S_1\) e \(S_2\). O fluxo total pela superfície fechada é simplesmente o fluxo do hemisfério sozinho. Por quê? Qual propriedade do campo \(\vec{F} = (x,y,z)\) no plano \(z = 0\) explica isso?

    ARQUIVO AUXILIAR [SIGMA-7]
    [NOTA TÉCNICA]: No disco \(z = 0\), o campo é \(\vec{F} = (x,y,0)\) — um vetor horizontal. A normal do disco (para baixo) é \(\hat{n} = (0,0,-1)\). O produto escalar de um vetor horizontal com um vertical é sempre zero. O disco não contribui para o fluxo porque o campo é radial e, na base, ele é paralelo ao disco.
