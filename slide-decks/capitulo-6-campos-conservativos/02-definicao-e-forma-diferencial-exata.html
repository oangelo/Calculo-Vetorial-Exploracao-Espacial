O Trabalho Depende do Caminho?

No capítulo 5 o trabalho de um campo ao longo de uma curva era sempre calculado por parametrização: cada trajeto, uma integral nova. Mas a pergunta que abre este capítulo é outra: e se, para certos campos, o percurso fosse irrelevante — e só os extremos importassem?

A resposta depende de uma propriedade do próprio campo, não da curva. Para reconhecê-la, precisamos olhar para o campo de uma forma nova: não como uma coleção de vetores soltos, mas como algo que pode "nascer" de uma única função.

O Campo Que Vem de Uma Função

Um campo conservativo é um campo vetorial que "vem de" uma função: em vez de vetores arbitrários em cada ponto, existe uma função \(f(x,y)\) cujas derivadas parciais produzem exatamente aqueles vetores. O campo é o gradiente de \(f\).

Analogia: a gravidade e um mapa de altitude. O mapa guarda uma única informação por ponto — a altitude. O desnível entre dois pontos não depende do trajeto que se escolhe entre eles: a diferença de altitude é a mesma por qualquer caminho. Campo conservativo é isso: existe um "mapa de altitude" escondido por trás dos vetores.

O trabalho ao longo de qualquer curva entre dois pontos seria então apenas a diferença de "altitude" entre os extremos — se o campo for conservativo.

Definição — Campo Conservativo

\[ \vec{F} \text{ é conservativo } \iff \exists f : \vec{F} = \nabla f \]

Onde:

Para \(\vec{F} = (M, N)\) em duas dimensões, ser \(\vec{F} = \nabla f\) significa que \[ M = \frac{\partial f}{\partial x} \quad \text{e} \quad N = \frac{\partial f}{\partial y} \]

Termos: \(f\) é a função potencial do campo — o "mapa de altitude" escondido.

Validade: \(f\) de classe C¹; o gradiente de \(f\) reproduz \(\vec{F}\) em todo o domínio.

A Forma Diferencial M dx + N dy

Existe uma segunda grafia para a integral de linha — e ela revela a estrutura do integrando. Escrever \(\vec{F} \cdot d\vec{r}\) é o mesmo que somar \(M\,dx + N\,dy\): aqui \(dx\) e \(dy\) não são símbolos soltos, mas as variações da posição ao longo da curva.

\[ \int_C \vec{F} \cdot d\vec{r} = \int_C M\,dx + N\,dy \]

A expressão \(\omega = M\,dx + N\,dy\) é a forma diferencial associada ao campo. Quando o campo é conservativo, \(\omega = df\), a diferencial da função potencial.

A notação não é acadêmica: foi na termodinâmica — nos estudos de calor e trabalho — que essa escrita revelou sua força, distinguindo grandezas que dependem do processo das que dependem só dos extremos.

A Condição de Exatidão

Se \(\omega = M\,dx + N\,dy\) for a diferencial de uma função — isto é, se for exata —, as componentes carregam uma assinatura algébrica: as derivadas mistas de \(f\) coincidem, e essa coincidência recai sobre \(M\) e \(N\).

\[ \omega = M\,dx + N\,dy \text{ exata } \Rightarrow \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \]

Termos: a igualdade das derivadas mistas é o teorema de Schwarz — para funções C², a ordem das derivadas não altera o resultado.

Equivalência vetorial: para \(\vec{F} = (M, N, 0)\), a condição acima é o mesmo que \((\nabla \times \vec{F})_z = 0\): o rotacional tem componente \(z\) nula.

Quatro Olhares para o Mesmo Campo

Em domínio adequado, as quatro afirmações dizem a mesma coisa:

(i) Gradiente

\(\vec{F} = \nabla f\) — existe função potencial.

(ii) Caminho

A integral de linha independe do caminho.

(iii) Forma

\(\omega = M\,dx + N\,dy\) é exata.

(iv) Rotacional

\(\nabla \times \vec{F} = \vec{0}\).

Aviso: a equivalência entre (i)–(iv) supõe um domínio sem "furos". Onde houver furos, a cadeia se rompe — essa sutileza topológica é o tópico 06; por ora, domínios simples.

Exemplo 1 — Reconhecimento por Inspeção

Verifique, por inspeção, quais das formas abaixo são exatas:

\[ \omega_1 = 2x\,dx + 2y\,dy \quad \text{e} \quad \omega_2 = -y\,dx + x\,dy \]

Para cada uma, decida se existe \(f\) com \(\omega = df\) e, se existir, encontre-a.

Estratégia: leia \(M\) e \(N\) de cada forma e compare as derivadas parciais cruzadas \(\partial M/\partial y\) e \(\partial N/\partial x\). Quando a igualdade valer, procure \(f\) por antiderivação direta de cada componente.
