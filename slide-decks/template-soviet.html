Conteúdo Matemático

A integral dupla de \(f(x,y)\) sobre a região \(D \subset \mathbb{R}^2\) é definida como:

\[\iint_D f(x,y) \, dx \, dy = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i, y_i) \Delta A_i\]

Quando \(D = [a,b] \times [c,d]\), aplicamos o Teorema de Fubini:

\[\iint_D f(x,y) \, dx \, dy = \int_a^b \left( \int_c^d f(x,y) \, dy \right) dx\]

Contexto Histórico

CONTEXTO

Era Sputnik (1957-1961)

O lançamento do Sputnik 1 pela União Soviética em 4 de outubro de 1957 iniciou uma corrida tecnológica sem precedentes. A NASA foi criada em resposta, e o programa Explorer precisava calcular com precisão a distribuição de massa em satélites.

NECESSIDADE

Modelagem de Sistemas Espaciais

Os engenheiros do programa Explorer precisavam calcular a distribuição de densidade de materiais em superfícies bidimensionais. As integrais duplas forneceram o framework matemático para otimizar painéis solares.

Problema + Solução

Problema:

Calcule \(\iint_D (x + y) \, dx \, dy\) onde \(D = [0,1] \times [0,2]\).

Solução:

\(\displaystyle\int_0^1 \int_0^2 (x+y) \, dy \, dx\)

\(= \displaystyle\int_0^1 \left[xy + \frac{y^2}{2}\right]_0^2 dx = \int_0^1 (2x + 2) \, dx\)

\(= \left[x^2 + 2x\right]_0^1 = 1 + 2 = \mathbf{3}\)

Dual Panel

Definição

Seja \(f: D \to \mathbb{R}\) contínua sobre o retângulo \(D = [a,b] \times [c,d]\).

\[\iint_D f \, dA = \int_a^b \int_c^d f(x,y) \, dy \, dx\]

Exemplo

Calcule sobre \(D = [0,1]^2\):

\[\iint_D x^2 y \, dA = \int_0^1 \int_0^1 x^2 y \, dy \, dx\]

\(= \int_0^1 \frac{x^2}{2} \, dx = \frac{1}{6}\)

// Integral dupla — soma de Riemann
function riemannSum(f, a, b, c, d, n) {
  let dx = (b - a) / n;
  let dy = (d - c) / n;
  let sum = 0;
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      let x = a + (i + 0.5) * dx;
      let y = c + (j + 0.5) * dy;
      sum += f(x, y) * dx * dy;
    }
  }
  return sum;
}
